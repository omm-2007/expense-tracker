# Expense Tracker 💰

A simple Python-based expense tracker that lets users record expenses, view spending, and calculate total expenditure through an interactive command-line interface.

### Features

* Add expenses
* View recorded expenses
* Calculate total spending

### Tech Stack

* Python 3

### Run Locally

```bash
python expense_tracker.py
```
